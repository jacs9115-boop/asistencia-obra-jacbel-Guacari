Registro manual (retroactivo)

Úsalo cuando no se pudo marcar asistencia ese día, o cuando el encargado no alcanzó a registrar con foto. Llena la entrada, la salida, o ambas. Queda guardado en el reporte marcado como "Manual".
Debes llenar al menos una de las dos horas.

PIN de seguridad

Este PIN lo usas tú (el contratista) para agregar o quitar trabajadores y para editar horas. El encargado no lo conoce, así que no puede modificar esta información sin comunicarse contigo.
